## ToDoList-.NET-MVC
A .NET MVC web application, made by Daniel Tenev in 2025.

A simple, Google Docs-like web app for creating, editing, viewing and deleteing documents. A login and a simple moderation system is implemented. A user can see their own documents only.

This project was built as a personal one while learning ASP.NET Core MVC and Entity Framework and doesn't act as a production system. It is still in development!

## Built with:
— C# / .NET 8, ASP.NET Core MVC  
— Entity Framework Core  
— SQL Server LocalDB  
— Bootstrap 5 for styling
